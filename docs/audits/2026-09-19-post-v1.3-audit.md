# Post v1.3.0 audit — SentinelPy

**Date:** 2026-09-19  
**Baseline:** `main` at tag **v1.3.0**

## Summary

v1.3.0 delivers the **CI & contract trust pack** planned in the v1.3 direction audit: documented GitHub Actions usage, golden JSON fixtures, and regression tests tying docs, CLI exit codes, schema, and renderers together. Runtime scan behavior and `report_schema_version` (`1.0.0`) are unchanged.

## P0 / P1

None identified at this baseline.

## Contract health

- **125** pytest cases, ~**89%** coverage.
- Golden fixtures under `tests/fixtures/reports/` validated on every CI run.
- Completed and error report categories covered by schema tests (v1.2.1–v1.2.2).

## Recommended next direction (v1.4+)

**Direction B — Operator ergonomics (still local, no SaaS):**

1. Optional **`--fail-on warning`** (or `--policy strict`) CLI flag mapping warnings to exit code `1` for pipelines that do not want to parse JSON.
2. **`sentinelpy validate report.json`** subcommand: schema + secret-leak guards for artifacts produced elsewhere.
3. Expand **Markdown** redirect/finding sections with one CLI e2e using mocked multi-hop responses.

**Non-goals (unchanged):** crawling, port scanning, new header categories without a major product decision, PyPI publish, telemetry, hosted UI, authentication.
